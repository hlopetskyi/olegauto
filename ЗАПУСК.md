# OlegAuto — Інструкція запуску

Цей документ описує все що потрібно зробити, щоб ваш магазин запрацював.
Слідуйте крокам по порядку. Якщо щось не виходить — скопіюйте помилку і дайте мені.

---

## Крок 1 — Встановити pnpm (один раз)

Відкрийте **Термінал** (знайдіть через Spotlight: ⌘ + пробіл → «Термінал»).

Вставте і натисніть Enter:
```
npm install -g pnpm
```

Перевірте що встановилось:
```
pnpm --version
```
Має показати щось на кшталт `9.x.x`

---

## Крок 2 — Встановити залежності

У терміналі перейдіть у папку бекенду:
```
cd ~/Documents/olegauto/backend
```

Встановіть всі пакети:
```
pnpm install
```
Це займе 1–3 хвилини.

---

## Крок 3 — Налаштувати базу даних (локально для тесту)

Для тестування на своєму комп'ютері потрібен PostgreSQL.

**Найпростіший спосіб — встановити через Homebrew:**
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install postgresql@16
brew services start postgresql@16
```

Потім створіть базу даних:
```
createdb olegauto_dev
```

**Або — одразу деплоїти на Railway** (Крок 6) і не встановлювати нічого локально.

---

## Крок 4 — Заповнити .env файл

У папці `backend` є файл `.env.example`. Скопіюйте його:
```
cp ~/Documents/olegauto/backend/.env.example ~/Documents/olegauto/backend/.env
```

Відкрийте файл `.env` у TextEdit і замініть значення:
```
DATABASE_URL=postgres://localhost/olegauto_dev
JWT_SECRET=будь-який-довгий-рядок-символів-123456
COOKIE_SECRET=інший-довгий-рядок-символів-654321
ADMIN_EMAIL=ваш@email.com
ADMIN_PASSWORD=ваш-пароль-для-адмінки
```

---

## Крок 5 — Запустити локально (для тесту)

```
cd ~/Documents/olegauto/backend
pnpm build
pnpm db:migrate
pnpm seed
pnpm dev
```

Після запуску відкрийте браузер і перейдіть на:
👉 **http://localhost:9000/app**

Введіть email і пароль що вказали в `.env` — ви в адмін-панелі!

---

## Крок 6 — Деплой на Railway (щоб сайт був в інтернеті)

### 6.1 Реєстрація
1. Зайдіть на **https://railway.app**
2. Натисніть «Sign Up» → увійдіть через GitHub
   (якщо немає GitHub — спочатку зареєструйтесь на **https://github.com**)

### 6.2 Нове середовище
1. На Railway натисніть **«New Project»**
2. Виберіть **«Deploy from GitHub repo»**
3. Підключіть ваш GitHub акаунт і виберіть репозиторій

> 💡 Якщо репозиторію ще немає — скажіть мені, я допоможу завантажити код на GitHub.

### 6.3 Додати PostgreSQL
1. У проекті на Railway натисніть **«+ New»** → **«Database»** → **«PostgreSQL»**
2. Після створення перейдіть у базу → вкладка **«Variables»**
3. Скопіюйте значення `DATABASE_URL`

### 6.4 Налаштувати змінні середовища
У налаштуваннях вашого сервісу на Railway → вкладка **«Variables»** додайте:

| Назва | Значення |
|-------|---------|
| `DATABASE_URL` | (з кроку 6.3) |
| `JWT_SECRET` | будь-який довгий рядок |
| `COOKIE_SECRET` | інший довгий рядок |
| `BACKEND_URL` | https://ваш-проект.up.railway.app |
| `ADMIN_CORS` | https://ваш-проект.up.railway.app |
| `NODE_ENV` | production |

### 6.5 Перший деплой
Railway автоматично збере і запустить проект. Через 3–5 хвилин сайт буде доступний за посиланням у вкладці **«Settings»** → **«Domains»**.

Адмін-панель буде за адресою:
👉 **https://ваш-проект.up.railway.app/app**

---

## Крок 7 — Що вмієте робити в адмін-панелі

Після входу в адмін-панель ви можете:

### Додати новий товар
1. **Products** → **«+ New product»**
2. Заповніть: назва, опис, ціна, кількість на складі
3. Завантажте фото
4. Додайте теги: марка авто, модель, рік
5. Натисніть **«Save»**

### Переглянути замовлення
- **Orders** — всі замовлення клієнтів
- Клік на замовлення → можна підтвердити, відправити, скасувати

### Керувати клієнтами
- **Customers** — список покупців, їх замовлення

### Налаштувати категорії
- **Categories** — структура каталогу (вже є базові категорії після seed)

## Швидкі команди (шпаргалка)

```bash
# Запустити локально
cd ~/Documents/olegauto/backend && pnpm dev

# Зупинити: натисніть Ctrl + C у терміналі

# Якщо щось зламалось — повністю перезапустити:
pnpm build && pnpm dev
```
