# Як запустити OlegAuto на своєму комп'ютері

## Перший раз (налаштування, один раз)

1. Відкрийте Термінал (⌘ + пробіл → «Термінал»)
2. Введіть:
   cd ~/Documents/olegauto/local-server
3. Потім:
   npm install
4. Дочекайтесь поки завершиться (1–2 хвилини)

## Щоразу для запуску

1. Відкрийте Термінал
2. Введіть:
   cd ~/Documents/olegauto/local-server && node server.js
3. Відкрийте браузер і перейдіть на:
   - Магазин: http://localhost:3000
   - Адмін: http://localhost:3000/admin

## Як зупинити

Натисніть Ctrl+C у терміналі
