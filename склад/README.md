# Inventa

Веб-додаток для складського обліку товарів зі штрих-кодами. Самостійний продукт: працює сам по собі,
а будь-який магазин чи CRM (у тому числі olegavto.com) підключається до нього збоку через API-ключ.

---

## Що він уміє

- **План складу.** Стелажі розставляються на схемі підлоги так, як вони реально стоять:
  перетягуванням, з поворотом уздовж або впоперек. Кожна комірка видна на плані окремо:
  наведення показує, які коробки й товари в ній лежать, клік відкриває повний вміст.
- **Довільна схема стелажа.** Комірки не прив'язані до прямокутної сітки — додаєте рівно
  стільки, скільки у вас ящиків, саме там, де вони стоять. Комірки можна додавати, прибирати,
  перетягувати й перейменовувати поштучно.
- **Коробки всередині комірок** — адреса стає «стелаж → комірка → коробка».
- **Штрих-код на кожне місце і на кожен товар.** Формат Code128 — читається будь-яким
  дешевим сканером-пістолетом.
- **Друк наклейок** — на звичайний принтер аркушем A4 або на термопринтер етикеток 58×40 мм.
- **Сканування** — сканером-пістолетом (він працює як клавіатура) або камерою телефона просто в браузері.
- **Схема стелажа.** Ввели код проданого товару — на схемі стелажа підсвітилася потрібна комірка.
- **Облік руху** — прихід, видача, переміщення, інвентаризація. Уся історія зберігається.
- **Мінімальні залишки** — видно, що закінчується.
- **Категорії з власними полями.** Форма створення товару універсальна, а специфіку задає
  категорія: для автозапчастин це OEM-номер і модель авто, для продуктів — термін придатності
  й номер партії. Є готові набори полів під типові бізнеси.
- **Фото товарів** — кілька знімків на позицію, стискаються прямо в браузері.
- **Заводські штрих-коди** — крім власного коду, товару можна прив'язати EAN з упаковки,
  і сканер знаходитиме товар за ним.
- **Імпорт із CSV** — з попереднім показом того, що буде створено й оновлено.
- **Експорт у CSV** — товари із залишками, історія рухів, місця зберігання.
- **Користувачі** — свій логін і пароль у кожного, в історії видно, хто зробив рух.
- **Інтеграції** — публічний API для зовнішніх магазинів.

## Важливо про штрих-коди

У самому штрих-коді зашитий **тільки ідентифікатор** — наприклад `P000123` для товару
або `L000045` для місця. Назва, кількість, місце розташування зберігаються в базі даних
і підтягуються при скануванні.

Це зроблено навмисно. Якби кількість була надрукована на наклейці, її довелося б переклеювати
після кожного продажу. А так наклейка друкується один раз і живе, поки живий товар чи полиця.

## Запуск

Один раз встановити залежності:

```bash
npm install
```

Запустити:

```bash
INVENTA_PASSWORD=ваш_пароль INVENTA_SECRET=довгий_випадковий_рядок npm start
```

Відкрити http://localhost:3200

Головна сторінка — **Склади**: підсумки по базі, перелік складів і те, що закінчується.
Клік по назві додатка ліворуч угорі повертає на головну й перезавантажує сторінку.

### Щоб додаток працював постійно (macOS)

Один раз виконати:

```bash
bash scripts/install-autostart.sh
```

Після цього Inventa стартує сама при вході в систему, піднімається назад, якщо процес
впаде, і завжди доступна за адресою **http://localhost:3200**. На робочому столі з'явиться
ярлик `Inventa` — подвійний клік відкриває додаток у браузері.

Корисні команди:

| Дія | Команда |
|---|---|
| Подивитись журнал | `tail -f data/logs/server.log` |
| Перезапустити | `launchctl kickstart -k gui/$UID/com.inventa.server` |
| Тимчасово зупинити | `launchctl bootout gui/$UID/com.inventa.server` |
| Увімкнути назад | `bash scripts/install-autostart.sh` |
| Зняти автозапуск зовсім | `bash scripts/uninstall-autostart.sh` |

Скрипт створює файл `data/.session-secret` і підставляє його як `INVENTA_SECRET`. Завдяки
цьому вхід не злітає після перезавантаження комп'ютера. Файл не потрапляє в git.

Змінні оточення:

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `PORT` | порт | `3200` |
| `INVENTA_PASSWORD` | пароль для входу | `inventa` |
| `INVENTA_SECRET` | ключ підпису сесій | `change-me-in-production` |
| `INVENTA_DATA_DIR` | де лежить база | `./data` |

**Обов'язково задайте свої `INVENTA_PASSWORD` і `INVENTA_SECRET` перед тим, як виставляти додаток
в інтернет.** Зі значеннями за замовчуванням увійти зможе будь-хто, хто знає адресу.

База даних — файл `data/sklad.db` (SQLite). Резервна копія = звичайне копіювання цього файлу.
При кожному запуску додаток сам кладе копію бази в `data/backups/` і тримає останні 10.
Каталог даних можна винести в інше місце змінною `INVENTA_DATA_DIR`.
Старі назви змінних із префіксом `SKLAD_` теж працюють.

## Як цим користуватися щодня

### Перше налаштування

1. **Склади** → створити склад (наприклад «Гараж на Зеленій»).
2. Всередині складу → **＋ Стелаж**. Вказати коротку назву (`С1`) і вибрати заготовку:
   - **Один довгий ряд** — вкажіть, скільки на стелажі ящиків. Найчастіший випадок.
   - **Прямокутник** — полиць × секцій, якщо стелаж саме такий.
   - **Порожній** — намалюєте схему з нуля.
3. Відкриється схема стелажа. Натисніть **✎ Редагувати схему** і доведіть її до реального вигляду:
   **＋** додає комірку саме там, де стоїть ящик; **✎** перейменовує; **✥** переміщує; **✕** прибирає.
   Штрих-код кожній новій комірці видається автоматично.
4. Кнопка **↻** кладе стелаж горизонтально або ставить вертикально — як він стоїть насправді.
5. Поверніться до **плану складу** і перетягніть стелажі туди, де вони стоять у приміщенні.
   Тягнути треба за смужку з назвою стелажа; поки тягнете, рамка показує, куди саме він стане,
   і червоніє, якщо місце вже зайняте іншим стелажем. Стелаж стає рівно по клітинках сітки
   і впритул до країв плану. На телефоні: довге натискання на стелаж, потім тик у потрібне місце.
   Кнопка **Розмір плану** міняє габарити «підлоги».
6. Якщо щось лежить не в стелажі — **＋ Вільне місце** (піддон, кут, вітрина).
7. У будь-якій комірці можна створити **коробку** — адреса стане «стелаж → комірка → коробка».

### Друк наклейок місць

**Наклейки** → вибрати «Усі місця складу …» або натиснути «🖨 Наклейки стелажа» на самому стелажі →
вибрати формат → **Друк**. Наклеїти на полиці й коробки.

### Дії над кількома товарами одразу

На сторінці **Товари** кнопка **☑ Вибрати** вмикає режим позначок: у плитках з'являються
галочки, у списку — колонка з прапорцями та «вибрати всі». Знизу з'являється панель дій:

- **Копіювати** — створює копії позначених товарів разом із категорією, полями категорії
  та фото. Заводські штрих-коди й залишки не копіюються: коди унікальні, а копія
  створюється порожньою. До назви й артикулу додається «копія».
- **Перенести в категорію** — міняє категорію гуртом. Значення полів, яких у новій категорії
  немає, прибираються.
- **Перемістити залишки** — увесь залишок позначених товарів переїжджає в одне місце.
  Кожне переміщення пишеться в історію окремим рядком, тож видно, звідки що приїхало.
- **Видалити** — прибирає позиції разом з їхніми залишками.

### Завантажити товари з файлу

**Товари → ⭱ Імпорт**. Підійде CSV з Excel (він зберігає з крапкою з комою — це нормально).
Перший рядок — заголовки. Розпізнаються: **Назва** (обов'язкова), Артикул, Штрих-код,
Категорія, Одиниця, Ціна, Мінімальний залишок, Кількість, Місце, Примітка. Колонки, названі
так само, як поля обраної категорії, теж підхопляться. Кнопка «Завантажити зразок» дає готовий файл.

Після кнопки **Перевірити** видно, скільки товарів створиться, скільки оновиться і які рядки
з проблемами — і лише тоді з'являється кнопка імпорту. Якщо вказані колонки «Кількість» і «Місце»,
товар одразу оприбутковується в потрібну комірку. Товар вважається наявним, якщо збігся
артикул або штрих-код.

### Занести товари вручну

1. **Категорії** → створити категорії під свій асортимент (можна з підкатегоріями).
2. У потрібній категорії натиснути **⚙ Поля товару** й описати, що саме треба знати про такий товар:
   вибрати **готовий набір** (Автозапчастини, Продукти харчування, Одяг і взуття, Електроніка,
   Будматеріали) або додати поля вручну. Тип поля: текст, довгий текст, число, дата,
   вибір зі списку, так/ні. Підкатегорії успадковують поля батьківської.
3. **Товари** → **＋ Новий товар**. Вибрати категорію — і під основними полями з'являться саме її поля.
4. У картці товару → **＋ Прийняти на склад** → вибрати місце і кількість.
5. **🖨 Наклейка** → надрукувати й наклеїти на сам товар або пакет.
6. **📷 Додати фото** — на складі впізнати деталь по фото швидше, ніж по назві.
   Знімки стискаються в браузері, тому вантажаться швидко навіть з телефона.

Якщо на товарі вже є заводський штрих-код, впишіть його в поле **«Штрих-коди з упаковки»** —
далі сканер знаходитиме товар за рідним кодом виробника, і друкувати свою наклейку не доведеться.

Швидший спосіб для великої партії: відсканувати наклейку **місця**, у картці місця натиснути
«＋ Покласти сюди товар» — не доведеться шукати місце у списку.

### Знайти товар, який продали

Вкладка **Сканувати** → ввести артикул (або відсканувати наклейку) → додаток покаже картку товару,
повний шлях «склад → стелаж → комірка» і підсвітить потрібну комірку на схемі стелажа.

Кнопка **🗺 Показати на плані складу** підсвітить це саме місце на загальному плані — видно,
до якого стелажа в приміщенні йти.

Кнопка **Видати** одразу списує потрібну кількість.

### Перевірити, що лежить на полиці

Відсканувати наклейку **місця** — покаже перелік усього, що там є, і вкладені коробки.

Те саме без сканера: **Склади** → потрібний склад → навести курсор на комірку в стелажі.
Спливе підказка з назвами коробок і товарів. Клік по комірці відкриває повний список
із кнопками «Видати». Клік по назві стелажа веде до його схеми, а щоб пересунути стелаж
по плану — тягніть саме за назву.

## Налаштування

Вкладка **Налаштування** має три розділи.

### Вигляд

- **Назва у шапці** — можна поставити назву свого бізнесу замість «Inventa».
- **Тема** — світла (типова), темна або як у системі.
- **Акцентний колір** — шість варіантів; колір напису на кнопках підбирається автоматично,
  щоб текст лишався читабельним на будь-якому фоні.
- **Розмір клітинки на плані складу** — більша клітинка краще читається, але план ширший.

Налаштування спільні для всієї бази, тож усі, хто заходить у цей додаток, бачать однаковий вигляд.

### Безпека

- **Зміна пароля.** Поки пароль не змінювали тут, він береться зі змінної оточення
  `INVENTA_PASSWORD`. Після першої зміни джерелом стає сам додаток: пароль зберігається
  як scrypt-хеш, у відкритому вигляді його немає ніде. Зміна пароля завершує сесії
  на всіх інших пристроях.
- **Скільки днів пам'ятати вхід** — тривалість сесії.
- **Вийти на всіх пристроях** — миттєво розлогінює всі сесії, крім поточної.
  Стане в пригоді, якщо загубився телефон із відкритим складом.

### Користувачі

Поки жодного користувача не заведено, вхід іде спільним паролем. Щойно ви додасте першого
користувача, форма входу почне питати логін — **тому першим створіть себе**.

Доступ у всіх користувачів однаковий. Сенс окремих облікових записів у тому, що в історії
рухів видно, хто саме зробив кожну операцію. Записи лишаються, навіть якщо користувача
згодом видалили — ім'я там зберігається текстом.

Замість видалення працівника можна перевести в стан **«Вимкнений»**: увійти він не зможе,
але лишиться в списку. Останнього активного користувача видалити або вимкнути не можна —
інакше в додаток ніхто не зайде.

### Дані

Експорт у CSV (товари із залишками, історія рухів, місця зберігання), посилання на імпорт
і зразок файлу.

### Інтеграції

Видача й відкликання API-ключів для зовнішніх магазинів — детально описано нижче,
у розділі «Інтеграція з магазином».

---

## Сканери

**Сканер-пістолет (USB або Bluetooth).** Працює як клавіатура: друкує код і натискає Enter.
Нічого налаштовувати не треба — просто відкрийте вкладку «Сканувати», курсор стоїть у полі сам.

**Камера телефона.** Кнопка «📷 Камерою телефона» на вкладці сканування. Працює тільки на `https://`
або на `localhost` — така вимога браузерів. Тому для роботи з телефона склад треба виставити
під HTTPS-доменом.

## Інтеграція з магазином

Inventa не знає нічого про конкретний магазин. Магазин сам ходить у API з ключем.

1. **Налаштування → Інтеграції** → **＋ Підключити сервіс** → вказати назву й код (наприклад `olegavto`).
2. Скопіювати виданий ключ `sk_…` — це і є доступ.
3. Магазин надсилає запити на `/api/v1/…` із заголовком `X-Api-Key`.

### Основні виклики

Наявність і місце за артикулом:

```bash
curl -H "X-Api-Key: sk_..." \
  "https://inventa.example.com/api/v1/products/lookup?sku=7700274177"
```

Наявність для списку товарів (для сторінки каталогу):

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"7700274177"},{"external_id":"42"}]}' \
  https://inventa.example.com/api/v1/stock/check
```

Списати при продажу:

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"sku":"7700274177","qty":1,"note":"замовлення №123"}' \
  https://inventa.example.com/api/v1/stock/out
```

Прив'язати товар магазину до товару складу (щоб надалі шукати за `external_id`):

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"sku":"7700274177","external_id":"42","external_url":"https://olegavto.com/p/42"}' \
  https://inventa.example.com/api/v1/products/link
```

### Повний перелік ендпоінтів v1

| Метод | Шлях | Призначення |
|---|---|---|
| GET | `/api/v1/ping` | перевірка ключа |
| GET | `/api/v1/products` | список / пошук товарів |
| GET | `/api/v1/products/lookup` | пошук за `sku`, `external_id`, `barcode` або `q` |
| GET | `/api/v1/products/:id` | один товар |
| POST | `/api/v1/products/link` | прив'язати товар зовнішньої системи |
| POST | `/api/v1/stock/check` | наявність для списку товарів |
| POST | `/api/v1/stock/out` | списання (продаж) |
| POST | `/api/v1/stock/in` | прихід (повернення, поставка) |
| GET | `/api/v1/locate` | де лежить + координати для схеми |

Ключ можна відкликати або перевипустити в один клік у «Налаштування → Інтеграції» — магазин втратить
доступ негайно, решта даних не постраждає.
