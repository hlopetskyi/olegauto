# Склад запчастин

Веб-додаток для обліку запчастин зі штрих-кодами. Самостійний продукт: працює сам по собі,
а будь-який магазин чи CRM (у тому числі olegavto.com) підключається до нього збоку через API-ключ.

---

## Що він уміє

- **План складу.** Стелажі розставляються на схемі підлоги так, як вони реально стоять:
  перетягуванням, з поворотом уздовж або впоперек.
- **Довільна схема стелажа.** Комірки не прив'язані до прямокутної сітки — додаєте рівно
  стільки, скільки у вас ящиків, саме там, де вони стоять. Комірки можна додавати, прибирати,
  перетягувати й перейменовувати поштучно.
- **Коробки всередині комірок** — адреса стає «стелаж → комірка → коробка».
- **Штрих-код на кожне місце і на кожну запчастину.** Формат Code128 — читається будь-яким
  дешевим сканером-пістолетом.
- **Друк наклейок** — на звичайний принтер аркушем A4 або на термопринтер етикеток 58×40 мм.
- **Сканування** — сканером-пістолетом (він працює як клавіатура) або камерою телефона просто в браузері.
- **Схема стелажа.** Ввели код проданої деталі — на схемі стелажа підсвітилася потрібна комірка.
- **Облік руху** — прихід, видача, переміщення, інвентаризація. Уся історія зберігається.
- **Мінімальні залишки** — видно, що закінчується.
- **Інтеграції** — публічний API для зовнішніх магазинів.

---

## Важливо про штрих-коди

У самому штрих-коді зашитий **тільки ідентифікатор** — наприклад `P000123` для деталі
або `L000045` для місця. Назва, кількість, місце розташування зберігаються в базі даних
і підтягуються при скануванні.

Це зроблено навмисно. Якби кількість була надрукована на наклейці, її довелося б переклеювати
після кожного продажу. А так наклейка друкується один раз і живе, поки жива деталь чи полиця.

## Запуск

Один раз встановити залежності:

```bash
npm install
```

Запустити:

```bash
SKLAD_PASSWORD=ваш_пароль SKLAD_SECRET=довгий_випадковий_рядок npm start
```

Відкрити http://localhost:3200

Змінні оточення:

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `PORT` | порт | `3200` |
| `SKLAD_PASSWORD` | пароль для входу | `sklad` |
| `SKLAD_SECRET` | ключ підпису сесій | `change-me-in-production` |

**Обов'язково задайте свої `SKLAD_PASSWORD` і `SKLAD_SECRET` перед тим, як виставляти додаток
в інтернет.** Зі значеннями за замовчуванням увійти зможе будь-хто, хто знає адресу.

База даних — файл `data/sklad.db` (SQLite). Резервна копія = звичайне копіювання цього файлу.

## Як цим користуватися щодня

### Перше налаштування

1. **Склади** → створити склад (наприклад «Гараж на Зеленій»).
2. Всередині складу → **＋ Стелаж**. Вказати коротку назву (`С1`) і вибрати заготовку:
   - **Один довгий ряд** — вкажіть, скільки на стелажі ящиків. Найчастіший випадок.
   - **Прямокутник** — полиць × секцій, якщо стелаж саме такий.
   - **Порожній** — намалюєте схему з нуля.
3. Відкриється схема стелажа. Натисніть **✎ Редагувати схему** і доведіть її до реального вигляду:
   **＋** додає комірку саме там, де стоїть ящик; **✎** перейменовує; **✥** переміщує; **✕** прибирає.
   Штрих-код кожній новій комірці видається автоматично.
4. Кнопка **↻** кладе стелаж горизонтально або ставить вертикально — як він стоїть насправді.
5. Поверніться до **плану складу** і перетягніть стелажі туди, де вони стоять у приміщенні.
   На телефоні: довге натискання на стелаж, потім тик у потрібне місце плану.
   Кнопка **Розмір плану** міняє габарити «підлоги».
6. Якщо щось лежить не в стелажі — **＋ Вільне місце** (піддон, кут, вітрина).
7. У будь-якій комірці можна створити **коробку** — адреса стане «стелаж → комірка → коробка».

### Друк наклейок місць

**Наклейки** → вибрати «Усі місця складу …» або натиснути «🖨 Наклейки стелажа» на самому стелажі →
вибрати формат → **Друк**. Наклеїти на полиці й коробки.

### Занести запчастини

1. **Запчастини** → **＋ Нова запчастина**. Заповнити назву, артикул, OEM-номер, марку й модель авто.
2. У картці деталі → **＋ Прийняти на склад** → вибрати місце і кількість.
3. **🖨 Наклейка** → надрукувати й наклеїти на саму деталь або пакет.

Швидший спосіб для великої партії: відсканувати наклейку **місця**, у картці місця натиснути
«＋ Покласти сюди деталь» — не доведеться шукати місце у списку.

### Знайти деталь, яку продали

Вкладка **Сканувати** → ввести артикул (або відсканувати наклейку) → додаток покаже картку деталі,
повний шлях «склад → стелаж → комірка» і підсвітить потрібну комірку на схемі стелажа.

Кнопка **🗺 Показати на плані складу** підсвітить це саме місце на загальному плані — видно,
до якого стелажа в приміщенні йти.

Кнопка **Видати** одразу списує потрібну кількість.

### Перевірити, що лежить на полиці

Відсканувати наклейку **місця** — покаже перелік усього, що там є, і вкладені коробки.

## Сканери

**Сканер-пістолет (USB або Bluetooth).** Працює як клавіатура: друкує код і натискає Enter.
Нічого налаштовувати не треба — просто відкрийте вкладку «Сканувати», курсор стоїть у полі сам.

**Камера телефона.** Кнопка «📷 Камерою телефона» на вкладці сканування. Працює тільки на `https://`
або на `localhost` — така вимога браузерів. Тому для роботи з телефона склад треба виставити
під HTTPS-доменом.

## Інтеграція з магазином

Склад не знає нічого про конкретний магазин. Магазин сам ходить у API складу з ключем.

1. Вкладка **Інтеграції** → **＋ Підключити сервіс** → вказати назву й код (наприклад `olegavto`).
2. Скопіювати виданий ключ `sk_…` — це і є доступ.
3. Магазин надсилає запити на `/api/v1/…` із заголовком `X-Api-Key`.

### Основні виклики

Наявність і місце за артикулом:

```bash
curl -H "X-Api-Key: sk_..." \
  "https://sklad.example.com/api/v1/parts/lookup?sku=7700274177"
```

Наявність для списку товарів (для сторінки каталогу):

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"7700274177"},{"external_id":"42"}]}' \
  https://sklad.example.com/api/v1/stock/check
```

Списати при продажу:

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"sku":"7700274177","qty":1,"note":"замовлення №123"}' \
  https://sklad.example.com/api/v1/stock/out
```

Прив'язати товар магазину до деталі складу (щоб надалі шукати за `external_id`):

```bash
curl -X POST -H "X-Api-Key: sk_..." -H "Content-Type: application/json" \
  -d '{"sku":"7700274177","external_id":"42","external_url":"https://olegavto.com/p/42"}' \
  https://sklad.example.com/api/v1/parts/link
```

### Повний перелік ендпоінтів v1

| Метод | Шлях | Призначення |
|---|---|---|
| GET | `/api/v1/ping` | перевірка ключа |
| GET | `/api/v1/parts` | список / пошук деталей |
| GET | `/api/v1/parts/lookup` | пошук за `sku`, `external_id`, `barcode` або `q` |
| GET | `/api/v1/parts/:id` | одна деталь |
| POST | `/api/v1/parts/link` | прив'язати товар зовнішньої системи |
| POST | `/api/v1/stock/check` | наявність для списку товарів |
| POST | `/api/v1/stock/out` | списання (продаж) |
| POST | `/api/v1/stock/in` | прихід (повернення, поставка) |
| GET | `/api/v1/locate` | де лежить + координати для схеми |

Ключ можна відкликати або перевипустити в один клік на вкладці «Інтеграції» — магазин втратить
доступ негайно, решта даних не постраждає.

## Структура коду

```
server.js        точка входу, авторизація, адмін-API для інтерфейсу
db.js            схема SQLite і генератори штрих-кодів
lib/store.js     уся бізнес-логіка: склади, місця, залишки, рухи, сканування
routes/v1.js     публічний API для зовнішніх систем
public/          інтерфейс: index.html, app.js, styles.css
data/sklad.db    база даних (у git не потрапляє)
```
